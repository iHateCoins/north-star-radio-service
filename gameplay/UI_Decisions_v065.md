# Player interface decisions — v0.65

| Area | Decision | Reason |
|---|---|---|
| Graph checks, circuit map, wiring audit, source scope, factory notebook, build overlay | Engineering mode only (`?engineering=1`) | Development evidence is not a repair action or a player upgrade. |
| Bench, schematic, part selection, meter, tube tester, discharge and checkout | Keep directly accessible | Required for the normal repair loop. |
| VTVM, capacitor checker, signal tracer | One Upgrades panel; owned tools appear on the bench | Useful diagnostic convenience with an existing price, rather than locked empty tabs. |
| Generator/alignment | Keep included; fold adjustments and supply settings | Real service capability without constant exposure to rarely used controls or a new paywall. |
| Normal readings | Match selected meter and range | Starter tools remain sufficient and their loading is understandable. |
| Physical source/variant caveats | Reference notes disclosure | Available for interested players without occupying routine diagnosis space. |
| Routine actions log | Collapsed Bench notes | Repeated messages should not compete with diagnosis. Heat/failure warnings open it automatically. |
| Return unrepaired | Job options, with existing confirmation | Infrequent action, available when needed. |
| First-run instructions | Three steps; full Service manual remains available | Begin repairing without reading an engineering notebook. |
| Mobile counter | First when no job is selected | The next action is visible before an empty bench. |

No simulation or damage-rule changes. All V2 acceptance sentences and all nine closures remain intact. Equipment prices, cash, inventory and previously purchased tools are preserved.
